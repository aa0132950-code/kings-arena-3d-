# Kings Arena 3D

An original Android-first 3D football prototype made with Godot 4.

## Included in this starter
- Mobile-friendly Compatibility renderer.
- Procedurally generated 3D training pitch and goals.
- One controllable capsule player.
- A physics ball.
- Keyboard controls for editor testing.
- On-screen directional and sprint buttons for touch testing.

## Controls
- Keyboard: WASD or arrow keys.
- Sprint: Shift.
- Android: use the on-screen direction buttons and SPRINT.

## Open the project
1. Download and extract this ZIP.
2. Open Godot 4.3 or newer.
3. Import the folder containing `project.godot`.
4. Run the main scene.

## Development status
This is only the first playable foundation. It is not yet a complete 7v7 match, online multiplayer game, or club-management game.
